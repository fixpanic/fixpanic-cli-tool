# Platform Support

The OpsSquad CLI is designed to run on all major operating systems and architectures.

| Platform | Architecture | Status | Notes |
|----------|--------------|--------|-------|
| **Linux** | amd64 (x86_64) | ✅ Supported | Most common server architecture. |
| **Linux** | arm64 (aarch64) | ✅ Supported | AWS Graviton, Raspberry Pi 4+, etc. |
| **Linux** | 386 (x86) | ✅ Supported | Legacy 32-bit systems. |
| **Linux** | arm (v6/v7) | ✅ Supported | Older Raspberry Pi, embedded devices. |
| **macOS** | amd64 (Intel) | ✅ Supported | Intel-based Macs. |
| **macOS** | arm64 (Apple Silicon) | ✅ Supported | M1, M2, M3 chips. |
| **Windows**| amd64 | ✅ Supported | Windows Server, Windows 10/11. |

## System Requirements
- **OS**: Modern Linux distribution (Ubuntu, Debian, CentOS, RHEL, Alpine), macOS 10.15+, or Windows 10+.
- **Memory**: Minimal footprint (<50MB RAM typically).
- **Disk**: ~50MB for binary and logs.
